# allfantasy-social

Public image hosting for AllFantasy's daily social posts. Buffer reads the images from here
when it publishes to Instagram, Facebook, X and TikTok.

`posts/<YYYY-MM-DD>/post-N.png`, 1080×1350. Generated by `marketing/social/render-daily.mjs`
on the `marketing/social-posts` branch of the main AllFantasy repo. Nothing here is code.
